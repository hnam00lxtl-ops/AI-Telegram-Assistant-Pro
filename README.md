# AI Telegram Assistant Pro

Trợ lý AI Telegram chạy bằng Ollama.

## Chức năng

- Chat AI
- Bộ nhớ dài hạn
- SQLite
- Đọc PDF
- Đọc Word
- Vision AI
- Internet Search
- Admin Panel
- Voice
- Plugin

## Cài đặt

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Cài thư viện:

```bash
pip install -r requirements.txt
```

Tạo file `.env` từ `.env.example`, điền BOT_TOKEN rồi chạy:

```bash
python bot.py
```
